# New-character attack pose sheets

Static character artwork generated with the built-in ImageGen tool. Each character has an independent transparent 2x2 PNG sheet, with four poses in reading order. Exact generation prompts and identity-reference paths are recorded in `prompts.json`.

These assets are not registered in the game. No cards, animation implementations, preloads, or live asset manifests are changed. Future integration should measure the generated cell boundaries and visible contact points before playback.

The sheets follow Jay's redrawn connected anatomy and Pristo's expressive four-pose layout. Each sequence is based on the new character's source description. Ida uses her maid outfit because her export's default Blank outfit contains no visible pixels.

The source-novel images remain staged separately in `output/new-novel-art/`. R2 upload still requires locally configured credentials. Retain artwork until uploads and public URLs are verified.
